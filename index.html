SPARQL Query Help & Instructions

Getting Started

  1. Select a Dataset: Choose from available datasets in the Dataset section
  2. Load Dataset: Click "Load Dataset" to configure the endpoint
  3. Use Examples: Browse example queries for your selected dataset
  4. Write Query: Use the query editor to write your SPARQL query
  5. Execute: Click "Execute Query" or use Ctrl+Enter

Query Guidelines

  • FROM Clause: Must match the loaded dataset's Graph URI
  • Prefixes: Use the Prefixes button to insert common prefixes
  • Syntax: Ensure proper SPARQL syntax with correct brackets and semicolons

Keyboard Shortcuts

  • Ctrl + Enter - Execute query
  • Ctrl + / - Toggle comments (in query editor)

Results Features

  • Filtering: Use the filter input to search within results
  • Pagination: Navigate through large result sets
  • Export: Download results as CSV, JSON, or RDF
  • URI Links: Click on URIs to open them in new tabs

Troubleshooting

  • Query fails: Check syntax and FROM clause compatibility
  • No results: Verify dataset content and query conditions
  • Slow queries: Add LIMIT clauses and optimize filters
  • Connection issues: Verify endpoint URL and network connectivity

Need More Help?

For additional assistance with SPARQL queries or dataset-specific questions, please contact the TALOS AI4SSH support team.
